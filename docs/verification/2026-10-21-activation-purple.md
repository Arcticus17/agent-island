# 激活紫 + 中性四阶（三套主题统一）

日期：2026-10-21
范围：`src/themes/tokens.css`、`graphite.css`、`pure-black.css`、`terminal.css`

## 色板

用户给定：

| 用途 | 色值 |
| --- | --- |
| 激活紫（accent / 进行中 / 选中） | `#cba6f7` |
| 非激活面（卡片、控件） | `#181825` |
| 悬停 / 边框 | `#313244` |
| 底色 | `#11111b` |

在 `tokens.css` 里落成四个品牌 token：

```css
--accent-activation: #cba6f7;
--surface-base: #11111b;
--surface-inactive: #181825;
--surface-hover: #313244;
```

## 三套主题怎么用

| | 石墨玻璃 | 纯黑 | 终端 |
| --- | --- | --- | --- |
| `--accent-primary` | 激活紫 | 激活紫 | 激活紫 |
| `--status-working` | 激活紫 | 激活紫 | 激活紫 |
| 面/底色 | 保持原有半透明玻璃 | 保持纯黑 | **底色 `#11111b` / 非激活 `#181825` / 边框与悬停 `#313244`** |

即：**激活紫三套统一；中性四阶只在终端主题落地**（石墨的玻璃质感靠半透明面，换成不透明色就没玻璃了）。

终端主题下的映射：卡面/控件面/通知面 = `--surface-inactive`，默认描边/滚动条/悬停 = `--surface-hover`，
弹层 = `--surface-inactive` + `--surface-hover`，日志底再压暗一档 `#0b0b14` 保证正文对比。
