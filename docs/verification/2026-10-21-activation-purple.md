# 「激活紫」作为强调色

日期：2026-10-21
范围：`src/themes/tokens.css`、`src/themes/terminal.css`

## 定义

新增品牌 token：

```css
/* 「激活紫」：正在被激活 / 选中 / 进行中的语义色 */
--accent-activation: #a78bfa;
```

深色底上用偏亮的紫罗兰（`#a78bfa` 在 `#070708` 上对比度约 8.6:1，正文级可用）。

## 用在哪

终端主题里把"激活语义"的三处统一成它：

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| `--accent-primary` | 白 `#e8e8e8` | **激活紫** |
| `--status-working`（工作中） | 白 | **激活紫**（进行中=激活） |
| 选中 Agent 芯片 | 白底反相 | 紫字 + 12% 紫底 + 45% 紫描边 |
| 「更新 vX」按钮 | 白底黑字 | 紫底深字 |
| 焦点环 | 白虚线 | 紫虚线 |
| `--border-event` | 灰 | 灰里混 40% 紫（事件类卡片描边） |

其余状态色保持降饱和（已完成=灰绿、等待=暗金、错误=灰红），避免"处处彩色"把终端感冲掉。

## 验证

- 实机：选中芯片、更新按钮、用量条、"工作中"状态字都变成紫色（`mac-island-analysis/activation-purple.png`、`activation-purple-claude.png`）；
- 视觉基线：7 张 `terminal-*` 重生成，其余两套主题未受影响（14 张保持原样）。
