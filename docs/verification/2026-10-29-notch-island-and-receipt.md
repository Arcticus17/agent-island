## 改了什么

- **形态**：从悬浮胶囊（496×58、20px 全圆角、带边框）改成**贴顶刘海**——窗口高 40、宽度由内容决定（约 80–140）、
  只有下缘 16px 圆角、顶边与工作区顶边齐平；展开时同一位置长成 560 宽的面板。
- **折叠信息模型**：由"名字 / 会话 / 42% / 工作中"四段文字改为**纯图标**——1–3 个像素吉祥物 + 状态记号（方点/勾/竖条/叉）
  + 右侧计数（待处理件数优先，其次额度百分比）。Agent 名、会话名、身份来源进 `sr-only`/展开态。
- **工作回执**：日志卡改成回执行——时间羻 + 节点（人/Agent/工具三种形状）+ 等宽正文 + 距上一条的耗时；
  长记录可原地展开/收起；工具调用（role=Tool 或 `Bash(` 这类开头）用琥珀色节点标识。
- **结构化工具调用（后端）**：`ConversationMessage` 新增 `tool` / `detail` / `success` 三个可选字段；
  Claude 适配器把 `tool_use` 解析成回执行（工具名 + 命令/路径/搜索词），并用 `tool_use_id` 把后续
  `tool_result` 的成功/失败回挂到同一行。前端把工具名渲染成 BASH 标签、入参一行等宽、行尾成功/失败记号。
- **窗口几何**：默认贴主屏工作区顶部居中；`clampWindowPlacement` 最小宽度 360 → 180；
  折叠高度 60 → 40、隐藏态 13 → 8；展开仍固定 560 宽并按内容高度封顶。拖动把手只在展开态出现。
- **审批托盘**：改为从抬头下方整宽铺开（`top: 55px`、左右贴边），不再以浮动卡片压住板面。

## 真机跑了一次（2026-10-29 21:55，tauri dev）

- 应用正常启动：窗口尺寸 80×8、位置 (935, 0)，`WindowFromPoint(975,3)` 命中 Agent Island；`PrintWindow` 能看到
  64×3 的隐藏态刻度，说明 WebView2 渲染正常。
- **发现一：默认不可见。** 现有产品语义是"隐藏 → 悬停变胶囊 → 点击展开"，而刘海形态下隐藏态只剩一条 3px 刻度，
  在深色任务栏/顶栏上几乎看不见；新用户不会知道顶部中间有一个岛。
- **发现二：和顶部 Dock 打架。** 这台机器的桌面美化在 y≈0–90 放了常驻 Dock；刘海贴在 y=0，会画在 Dock 图标上方。
  窗口可命中、可置顶，但视觉上会和 Dock 抢位置。
- 自动化注入的 hover/热键没能驱动隐藏态展开（注入输入对 WebView 不可信）；**需要人工鼠标实测**一次
  "悬停 → 刘海 → 点击展开"。

### 改成默认常驻后的复测（22:2x）

- 重启后窗口为 **81×40、位置 (935, 0)**，刘海直接可见，不再需要悬停（截图 `.impeccable/review/notch-real.png`）。
- 仍未解决：刘海画在顶部 Dock 图标之上（截图里可见两个 Dock 图标被盖住）。下一步建议加一个"垂直偏移"设置，
  或者检测到顶部常驻 Dock 时自动下移。

## 明确没做的

- **Diff 呈现**：结构化字段已补 `tool` / `detail` / `success`，但 diff 本身（文件改动行数、unified diff）
  还没有字段；`tool_result` 的内容也只用于判定成功/失败。下一步是在解析侧读 diff 统计并按文件聚合。
- **终端内 cockpit**：参考里的分栏是 Claude Code 自己的 TUI，本应用不复制它。
- **技术栈**：不加、不换。仍是 Tauri 2 + Svelte 5。

## 已知限制

- 刘海贴在工作区顶边，最大化的窗口标题栏会被盖住一点；全屏应用仍会看到它（可手动隐藏）。
- 折叠宽度是按内容量出来的，中英文混排或多 Agent 时会在 82–140 之间变化；窗口宽度不再由用户拖动决定。
- 记录很少时回执区仍有留白（滚动视口固定 96/164/240）。
- 默认仍是"隐藏态"（只显示刻度）；刘海形态下建议改成默认显示刘海，这一项属于产品行为变更，等确认后再改。
- 只在 Playwright Chromium（Windows 字体）下比对；WebView2 实机、混合 DPI、多显示器仍需按公开发布门槛验收。
