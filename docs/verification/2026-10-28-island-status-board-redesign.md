# 主岛「状态板」视觉改造验证（2026-10-28）

范围：灵动岛主窗口（折叠胶囊、展开面板、审批/通知/收件箱、操作栏）。会话总览窗口与旧界面回退路径不在范围内。

## 改了什么

- **信息架构**：展开面板从"引导 → 收件箱 → Agent 芯片 → 检测 → 诊断 → 版本 → 全局搜索 → 审批规则 → 指令 → 会话选择 → 终端 → 卡片 → 操作"重排为
  "胶囊 → Agent 芯片 → 待你处理 → 数据板（状态/用量/会话/日志/统计）→ 指令 → 会话选择 → 终端 → 系统项（诊断/版本/搜索/审批规则）→ 操作栏"，并把卡片布局工具移到数据板下方。
- **视觉语言**：卡片盒子改为 1px 发丝分隔的寄存器行；去掉三层重复标签（"状态卡片 / 当前状态 / 工作中"）；日志变成带时间羻的纸带；
  交互色改为"墨"，色相全部留给状态；状态色只在"等待确认/报错"时整片点亮。
- **外观收敛**：三套主题（石墨玻璃/纯黑/终端）收敛为深色与浅色两态，同一套结构、字阶与动效。存储键 `agent-island-appearance-v1`，旧键的三种旧值按深色读取。
- **组件**：胶囊、状态/用量/会话/日志卡、操作栏、设置、收件箱、审批、通知、引导、指令输入、命令面板、全局搜索、审批规则、卡片故障兜底、终端配色。

## 已知限制

- 只在 Playwright Chromium（Windows 字体环境）下比对过；WebView2 实机、混合 DPI、多显示器仍需按公开发布门槛验收。
- 状态色相在深/浅两态下做了不同取值以满足浅底对比度，跨外观截图不能直接比对颜色值。
- 展开面板的日志区高度仍由卡片尺寸决定（96/164/240px），记录很少时会出现留白；这是滚动视口而不是布局错误。
- 会话总览窗口继续使用旧的三套主题（graphite / pure-black），与主岛并排看会有风格差异。
- Impeccable 引擎（context / concept-seed / document / detect）在本机无法下载，PRODUCT.md、方向契约与 DESIGN.md 按同一模板人工补齐；未生成 .impeccable/design.json，也没有跑自动设计检测器。
