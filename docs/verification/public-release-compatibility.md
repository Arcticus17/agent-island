# 公开发布适配门槛

目标是其他用户安装即可使用，不以开发者机器的测试结果代替兼容性。以下均为发布前待验收要求，不代表当前已经支持；安装器未经过这些检查前只作为测试版。

| 范围 | 必测场景 | 通过标准 |
| --- | --- | --- |
| 干净环境 | 无开发工具、无 Agent CLI、缺少 WebView2、断网 | 不依赖 Rust/Node 开发环境；缺少运行依赖时提供明确说明，不假成功 |
| 用户与路径 | 普通用户、中文用户名、空格目录、自定义安装目录、不同磁盘 | 不包含开发机用户名或盘符假设；拒绝访问时解释原因 |
| CLI 安装 | npm shim、独立 exe、自定义 PATH、安装后未重启应用 | 正确发现可执行文件；缺失时说明检测条件与恢复方法 |
| 会话来源 | 支持的 CLI 版本、长元数据、多个项目、多个进程、无日志 | 可靠匹配才展示当前对话；歧义/未知格式明确降级，禁止串会话 |
| 桌面显示 | 100/125/150/200% 缩放、混合 DPI、多屏拔插、任务栏位置 | 窗口可见且可操作；焦点正确；无矩形虚化、裁切和不可达按钮 |
| 设置与存储 | 首次使用、存储不可写、坏配置、重启、升级 | 配置持久化可验证；失败提示且不丢弃原数据 |
| 权限与安全 | 普通权限终端、提升权限终端、命令特殊字符 | 不静默提权、不执行拼接注入；失败反馈准确 |
| 分发 | 安装/覆盖升级/卸载、签名与安全软件检查 | 安装包与源码版本可对应；数据保留政策明确；未签名状态透明 |
| 无障碍 | 键盘导航、减少动画、高对比度、窄窗口 | 核心功能无需鼠标精确拖拽，状态不只靠颜色 |

## 发布流程

1. 固定首批目标系统、CPU 架构及 Agent CLI 版本矩阵；未实测的平台不得列为支持。
2. 完成自动回归，再在干净 Windows 环境运行安装器，记录系统、WebView2、CLI 版本与结果。
3. 核验原生操作：目录、终端、跳回、总览层级、恢复、hooks、DPI、多屏。
4. 发布前检查隐私默认值、脱敏诊断、升级迁移和安全配置；不自动上传日志。
5. 所有失败保留复现信息与修复记录，剩余限制写入 README 和发布说明。

macOS、Linux、ARM64 均不因技术栈理论支持而自动视作本项目已支持。框架替换只在复现验证现有框架无法满足某项要求后评估。
