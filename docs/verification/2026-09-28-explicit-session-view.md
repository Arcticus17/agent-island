# 显式本地会话查看

## 实现边界

胶囊增加手动选择本地会话入口，默认仍为可靠匹配的当前会话。手动查看不改写 active_session，不参与任务优先级或通知判定。目录与终端使用明确的所选会话；历史模式禁用进程级停止、重启、跳回。所选记录消失后不替换为另一对话。

Codex 扫描和用量支持 CODEX_HOME；历史展示优先明确 Desktop 根会话（严格 originator/source/thread_source/parent 组合），辅助日志保留在匹配候选中。

本地元数据抽样发现 source=vscode 的桌面根会话及大量辅助任务。因此不能凭 source=desktop、最新文件或 app-server PID 推断当前桌面任务。

官方 [App Server 文档](https://learn.chatgpt.com/docs/app-server) 说明了线程读取与通信协议，但本轮没有验证连接既有桌面服务的可用通道。没有启动额外 app-server、修改桌面配置或伪称实时桌面控制已接入。
