# 命令面板（Ctrl+K）

日期：2026-10-21
范围：`src/palette/commands.ts`（新）、`src/components/palette/CommandPalette.svelte`（新）、`src/app/App.svelte`、测试

## 为什么

岛默认是隐藏态，操作全靠鼠标点：切 Agent 要在顶部横向点、看历史会话要点下拉、开终端要点按钮。
键盘用户（以及只想敲两下就切过去的人）没有入口。`Ctrl+K` 是最不需要解释的约定。

## 内容

命令面板里的条目全部来自现有状态，不额外请求后端：

| 分组 | 例子 |
| --- | --- |
| Agent | Claude Code（工作中）、Codex CLI（等待确认）… |
| 会话 | 当前会话、历史会话（只列**当前** Agent 的，避免混淆） |
| 动作 | 打开内置终端、刷新快照、切换隐私遮罩、切换专注模式、收起灵动岛 |

匹配是子序列（`cc` 能命中 `Claude Code`），打分偏好连续命中与词首命中；↑↓ 循环选择，Enter 执行，Esc 关闭。

## 一个必须知道的布局坑

第一版把面板挂在事件层里，结果显示时被岛的顶栏压住一半——`position: fixed` 没生效成"相对窗口"。

原因：岛的根容器带 `backdrop-filter`，**滤镜/变换会给 fixed 后代建立新的包含块**，于是 `fixed` 变成相对那个容器定位。
修法：把 `<CommandPalette>` 挪到组件最外层（`<main>` 与 `<aside>` 之外），祖先链上没有滤镜，`inset: 0` 才真的铺满窗口。

## 验证

**实机**：`Ctrl+Shift+A` 展开 → `Ctrl+K` 打开面板，可见
`Claude Code / Codex CLI / <you>（历史会话）/ OpenCode / 打开内置终端 / 刷新快照 / 切换隐私遮罩 / 切换专注模式`，
底部提示 `↑↓ 选择 · Enter 执行 · Esc 关闭`；Esc 关闭正常。
截图：`mac-island-analysis/palette-live-2.png`。

| 层 | 用例 |
| --- | --- |
| 单测（4 条） | 命令拼装顺序与提示文案、只列当前 Agent 的会话、子序列匹配与排序、空查询返回全部、选择项环绕 |
| 浏览器（2 条） | `Ctrl+K` 打开 → 输入「终端」→ Enter 执行后面板关闭；↑↓ 切换选中项 + Esc 关闭 |
