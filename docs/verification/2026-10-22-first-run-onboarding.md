# 首次引导卡片

日期：2026-10-22
范围：`src/onboarding/state.ts`（新）、`src/components/onboarding/WelcomeCard.svelte`（新）、`src/app/App.svelte`、`src/palette/commands.ts`、测试与视觉基线

## 为什么

岛默认是屏幕顶上一条 13px 的缝，第一次用的人基本不可能自己发现
「Ctrl+Shift+A 唤出」「Ctrl+K 命令面板」。写文档没用——没人会先读文档。

## 卡片内容

展开面板顶部出现一次（收起状态不打扰）：

```
第一次用？三件事就够                                [知道了]
Ctrl+Shift+A   唤出 / 收起    平时它藏在屏幕顶部，用这个组合键叫出来
Ctrl+K         命令面板       切 Agent、切会话、开终端，键盘走完
允许 / 记住这条  处理审批      允许一次，或者把这类命令加进白名单
```

- 点「知道了」→ 写入 `agent-island-onboarded=1`，之后不再出现；
- 命令面板里保留「查看上手引导」，随时能再看一次（清空标记不必要）；
- 引导只出现在**展开态**，不会为了教学自动把岛弹开。

## 顺手修掉一个死命令

实现时发现命令面板里的「固定 / 取消固定当前 Agent」**只有列表项、没有处理分支**——
第七轮插入 switch 分支时的字符串替换静默失败了。已补上，现在这条命令真的能用。

这也说明：命令面板需要一个"每条命令都能被执行"的测试，而不是只测列表内容。

## 视觉基线

引导卡片会出现在所有展开态截图里，所以：

- 常规场景统一预设 `agent-island-onboarded=1`（截图不掺引导）；
- 新增 **`welcome` 场景**（三种主题各一张）专门覆盖引导卡片。

基线从 21 张变成 24 张。
